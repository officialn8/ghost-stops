# Archive

These documents describe Ghost Stops before the October 2026 revival: the Go ETL and its SQLite cache, the v1 ghost score, and the January 2026 glass redesign. All of that has since been replaced. They are kept as history and are not maintained.

For the system as built, read the repository `README.md` and `.claude/CLAUDE.md`. The revival plan (`docs/plans/2026-10-02-2208-feat-ghost-stops-revival-plan.md`) records why each piece changed, and the audit (`docs/audit-2026-10-02/`) records what was found first.
